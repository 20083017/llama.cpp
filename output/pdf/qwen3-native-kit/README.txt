This kit contains documentation, fixtures and a Python launcher for the existing native C++ example.
It does not contain model weights, compiled .so binaries or a custom libqwen_nlu.so implementation.
The launcher requires Python 3.9+ and runs the C++ executable locally, without HTTP.
Build the SDK on Linux and use its matching headers and libraries.
